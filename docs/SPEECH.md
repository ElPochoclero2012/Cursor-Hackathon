# Speech de presentación (2–3 min)

Frases de backup (también están como chips en Movimientos):

1. `Pasá 80 bolsas del lote 241 Agata de Dos Pancani al galpón.`
2. `Retirá 600 bolsas del lote 241 de Pancani.`

Pestaña **Movimientos** visible al empezar. Después Control y, si hay tiempo, Exportación.

Si el micrófono falla: tocá el chip y seguí con texto. Chrome para dictado.

---

## Guión

**Movimientos — problema y saldo (30 s)**  
Cuatro depósitos, planilla compartida, el faltante aparece en la entrega. Esta tabla es el saldo único.

**Movimientos — voz/texto (40 s)**  
Chip o frase 1 → **Interpretar** → **Confirmar**. Pancani baja, galpón sube.

**Movimientos — bloqueo (30 s)**  
Frase 2 → Interpretar → Confirmar. El sistema rechaza: no hay 600.

**Control — conteo (40 s)**  
Pestaña Control. Lote 241, Pancani, bolsas contadas **320**. **Registrar conteo**: hipótesis en español (movimiento no registrado). Bolsas a cargar **400** → **Emitir orden de carga** no sale.

**Exportación — proforma (30 s, si hay tiempo)**  
Pestaña Exportación. Lote **810**, galpón, 200 bolsas, Parmentier / Brasil. **Armar proforma**: ficha con trazabilidad (calibre, bolsa, procedencia). No documenta lo que el piso no tiene.

**Cierre**  
Sin planilla, sin OpenAI, una fuente de verdad, y no se carga ni se documenta lo que el piso no tiene.
